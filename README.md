# Gates Industrial Hypothetical LBO

An integrated private-equity underwriting project evaluating a hypothetical leveraged buyout of Gates Industrial Corporation. The analysis connects historical financial statements, segment-level operating forecasts, entry valuation, transaction financing, debt repayment, exit valuation and sponsor returns.

> **Disclaimer:** This is an academic portfolio project prepared for MSc Finance applications. It is based on public information and analyst assumptions and is not investment advice.

## Investment summary

The base case does not meet the illustrative 20% IRR and 2.0x MOIC screening thresholds. EBITDA growth and $1.711bn of debt repayment create value, but the high entry valuation, modest multiple contraction, transaction costs and early interest burden constrain sponsor returns.

The downside case produces a **(4.9%) IRR and 0.78x MOIC**. The upside case produces a **13.7% IRR and 1.90x MOIC**. The analysis therefore supports a disciplined **do-not-invest conclusion at the assumed entry price**, while identifying the changes required to improve returns.

## Workbook structure

1. **Summary** — consolidated historical, forecast, transaction and return outputs
2. **Historical FS** — historical income statement, balance sheet and cash-flow statement
3. **Segment History** — Power Transmission and Fluid Power performance
4. **EBITDA Bridge** — reported-to-adjusted EBITDA reconciliation
5. **Checks** — reconciliation and error controls
6. **Sources** — source documentation and URLs
7. **Assumptions** — editable downside, base and upside operating drivers
8. **Operating Model** — segment forecast and unlevered free cash flow
9. **Entry Valuation** — offer price and enterprise-value bridge
10. **Sources & Uses** — transaction funding and capitalisation
11. **Debt Schedule** — interest, mandatory amortisation and cash sweep
12. **Returns** — exit valuation, MOIC and IRR
13. **Scenario Analysis** — integrated downside, base and upside cases
14. **Sensitivities** — entry multiple, exit multiple and leverage matrices
15. **IC Summary** — recommendation, key assumptions, returns, value creation and audit status

## Key analytical conclusions

- Entry valuation is the principal constraint on sponsor returns.
- Debt repayment is the largest source of value creation in the base case.
- Higher leverage offers only limited improvement because incremental interest restricts the cash sweep.
- Even the upside case remains below the target return, indicating that a lower purchase price or stronger operating assumptions would be required.
- A robust model can support a decision not to invest; the purpose is disciplined underwriting, not manufacturing an attractive result.
