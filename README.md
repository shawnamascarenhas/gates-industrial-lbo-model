# Gates Industrial Hypothetical LBO

## Project overview

This portfolio project evaluates a hypothetical leveraged buyout of Gates Industrial Corporation. The model links historical financial statements, a segment-level operating forecast, entry valuation, transaction financing, debt repayment, exit valuation and sponsor returns.

The analysis is an academic exercise prepared for MSc Finance applications. It is not an investment recommendation.

## Submission files

- `Gates_Industrial_LBO_Final.xlsx` - complete formula-driven financial model
- `Gates_Industrial_LBO_Investment_Memo.pdf` - two-page investment committee memorandum
- `Gates_Industrial_LBO_IC_Presentation.pptx` - seven-slide investment committee presentation with editable charts
- `Gates_Industrial_LBO_Interview_Guide.docx` - model walkthrough, technical questions and interview preparation guide
- `APPLICATION_MATERIALS.md` - CV bullets, personal-statement copy and submission guidance
- `MODEL_AUDIT_REPORT.md` - independent formula, reconciliation and model-limitation review

## Workbook navigation

1. **Summary** - consolidated historical, forecast, transaction and return outputs
2. **Historical FS** - historical income statement, balance sheet and cash-flow statement
3. **Segment History** - Power Transmission and Fluid Power performance
4. **EBITDA Bridge** - reported-to-adjusted EBITDA reconciliation
5. **Checks** - independent reconciliation and error controls
6. **Sources** - source documentation and URLs
7. **Assumptions** - editable downside, base and upside operating drivers
8. **Operating Model** - segment forecast and unlevered free cash flow
9. **Entry Valuation** - offer price and enterprise-value bridge
10. **Sources & Uses** - transaction funding and capitalization
11. **Debt Schedule** - interest, mandatory amortization and cash sweep
12. **Returns** - exit valuation, MOIC and IRR
13. **Scenario Analysis** - integrated downside, base and upside cases
14. **Sensitivities** - entry multiple, exit multiple and leverage matrices
15. **IC Summary** - recommendation, key assumptions, returns, value creation and audit status

## Investment conclusion

The base case does not meet the illustrative 20% IRR and 2.0x MOIC screening thresholds. EBITDA growth and $1.711bn of debt repayment create value, but the high entry valuation, modest multiple contraction, transaction costs and early interest burden constrain sponsor returns.

The integrated downside case produces a negative 4.9% IRR and 0.78x MOIC. The upside case produces a 13.7% IRR and 1.90x MOIC.

## Suggested interview discussion

Be prepared to explain:

- Why Gates was selected as an LBO candidate
- Why the entry multiple is the largest return constraint
- How interest expense affects the cash sweep
- Why additional leverage provides limited improvement in this case
- How downside assumptions affect EBITDA, deleveraging and equity value
- Why a well-built model can support a decision not to invest
- Which assumptions would need to change to reach the target return

## Model conventions

- Blue font and pale-yellow cells indicate editable assumptions.
- Green font indicates links to other workbook sheets.
- Black font indicates same-sheet formulas.
- Monetary amounts are in USD millions unless stated otherwise.
- Forecast years are FY2026-FY2030.
- All model audit sections show `OK` in the delivered version.
